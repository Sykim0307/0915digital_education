일러두기 — 사용법

대시보드

경조사비와 선물을 합친 전체 현황을 한눈에 봐요.

  • 상단 타일: 경조사비로 나간/받은 금액, 선물을 금액으로 환산한 순잔액, 이 둘을 합친 총 정산금액
  • "통합 정산" 목록: 사람별로 경조사비+선물을 합쳐서 누구에게 더 받았는지/줬는지 확인

기록 (경조사비)

  1. "＋ 새 기록"을 눌러 이름·날짜·경조사 유형·금액·구분(냈어요/받았어요)을 입력
  2. 친밀도와 반응(선택)을 남기면 계산기·화이트/블랙리스트 분류에 반영돼요

계산기

이름을 입력하면 과거에 그 사람에게 받은 금액을 자동으로 찾아 반영해서, 경조사 유형·친밀도에 맞는 추천 금액을 계산해요.

기프티콘

  • "＋ 새 선물 기록"으로 직접 입력하거나, "카톡 텍스트로 추가"에서 대화를 붙여넣어 빠른 분석(규칙 기반) 또는 AI로 분석하기를 눌러 자동 채우기
  • 카톡 캡처나 영수증 사진이 있으면 "사진 분석하기"로 AI가 쿠폰명·가격대를 읽어드려요
  • 받은 선물은 표에서 "사용" 체크박스로 사용 여부를 표시하고, 유효기간이 14일 이내로 다가오면 상단에 경고가 떠요

사람

  • 이름·나이·직장·성향·최근 이슈·기념일을 등록해두면 프로필 카드가 생겨요
  • 카드마다 통합 정산 금액, 반응 기록을 바탕으로 한 화이트/블랙리스트 등급, 주고받은 이력 타임라인을 볼 수 있어요

데이터는 어디에 저장되나요?

이 화면은 세 가지 저장 방식 중 하나로 동작하고, 화면 오른쪽 위 상태 표시로 어떤 방식인지 확인할 수 있어요.

  • 이 기기·계정에 동기화됨 — claude.ai 계정으로 Artifact 링크를 열었을 때. 기기 간 동기화됨
  • 이 폴더의 data.json에 저장됨 — 아래 "로컬 서버로 실행하기"로 열었을 때. 프로젝트 폴더의 data.json 파일에 자동 저장됨
  • 이 브라우저에만 저장됨 — HTML 파일을 그냥 더블클릭해서 열었을 때. 그 브라우저에만 남고 파일로는 저장되지 않음

로컬 서버로 실행하기 (프로젝트 폴더의 data.json 자동 사용)

HTML 파일을 그냥 열면 브라우저 정책상 폴더 안의 JSON 파일을 자동으로 읽고 쓸 수 없어요. 대신 프로젝트 폴더의 server.js를 실행하면 같은 폴더의 data.json을 자동으로 불러오고, 기록을 추가·수정할 때마다 자동으로 그 파일에 저장돼요.

  1. 터미널(PowerShell)을 열고 프로젝트 폴더로 이동: cd C:\Users\user\Desktop\project
  2. node server.js 실행
  3. 브라우저에서 http://localhost:5173 접속 (HTML 파일을 직접 더블클릭하지 말고 이 주소로 열어야 해요)

서버를 끄지 않는 한 계속 그 폴더의 data.json에 저장되고, 다음에 다시 켜도 이어서 사용할 수 있어요.

데이터 내보내기 / 가져오기

계정(클라우드)에 저장된 데이터와 로컬 파일로 연 화면의 데이터는 서로 다른 저장소예요. 내보내기로 백업(JSON)을 받아서, 다른 화면(로컬 파일 등)에서 가져오기로 불러올 수 있어요. 가져오기는 기존 데이터를 지우지 않고 추가돼요.

Google 로그인 (내 계정으로 어디서든 접속)

Google로 로그인하면 이 계정 전용 데이터가 Supabase에 저장돼서, 로컬 서버 없이도 어느 기기·브라우저에서든 로그인만 하면 같은 기록을 볼 수 있어요. 로그인하지 않으면 기존처럼 로컬 파일/브라우저 저장소를 사용해요.

  1. Google Cloud Console에서 OAuth 클라이언트 ID 생성 (승인된 리디렉션 URI에 https://프로젝트ref.supabase.co/auth/v1/callback 추가)
  2. Supabase 대시보드 → Authentication → Providers → Google 활성화, 위 클라이언트 ID/Secret 입력
  3. Supabase 대시보드 → Authentication → URL Configuration → Redirect URLs에 http://localhost:5173 추가
  4. supabase/schema_users.sql을 SQL Editor에서 실행 (로그인 사용자별 테이블 생성)
  5. bongtu-ledger.html 안의 SUPABASE_ANON_KEY 값을 Supabase 대시보드 Settings → API의 anon(public) 키로 교체

설정 전에는 화면 오른쪽 위에 로그인 버튼이 아예 보이지 않아요.
